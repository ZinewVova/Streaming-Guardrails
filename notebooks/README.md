# Ноутбуки

- `01_singstreambench_eda.ipynb` проверяет происхождение, схему, 210 строк, четыре
  сочетания query/response labels, длины и точность onset/safe-prefix.
- `02_streaming_benchmark.ipynb` показывает конфигурацию Qwen3Guard, политики, шесть
  режимов буфера и загружает сохранённые результаты и CI. Каждый раздел сопровождается
  графиком: матрицы ошибок запроса и ответа, FPR/FNR с Wilson CI, потокенная трасса
  каждого примера, смещение сигнала относительно onset, leakage с bootstrap CI по
  режимам, парное сравнение с эталонным режимом и чувствительность к правилу остановки:
  числу флагов, счёту подряд и порогу по вероятности unsafe.
- `04_scm_benchmark.ipynb` проходит те же трассы моделью SCM-0.5B с правилом остановки
  Harm@k: качество блокировки ответа, потокенные вероятности на четырёх примерах,
  смещение сигнала, leakage по режимам буфера и чувствительность к порогу θ и числу
  флагов k.
- `06_model_comparison.ipynb` сравнивает все модели, у которых есть конфиг в `configs/`
  и сохранённый полный прогон: два вида ошибок блокировки, leakage в словах по режимам
  буфера, кривая «сколько вредных слов ушло до остановки», матрицы попарных разностей на
  одних трассах с поправкой Холма, сравнение при равной доле ложных блокировок по сетке
  правил остановки, пересечение ошибок и время проверки токена против ошибок. Модель
  запускать не нужно, но нужны сохранённые прогоны.

Ноутбуки моделей нумеруются по порядку, сводный стоит последним; свободные номера
оставлены под следующие модели.

Расчёты находятся в `src/streamguard_bench`; ноутбук только вызывает функции и строит
графики. Окружение собирается командой `make install`, подробности в
[`docs/setup.md`](../docs/setup.md). Открывать ноутбуки удобно в VS Code с расширениями
Python и Jupyter: выберите ядро из `.venv` и нажмите Run All.

Файлы хранятся вместе с выводами, чтобы таблицы и графики были видны без запуска. В
`01_singstreambench_eda.ipynb` при этом опубликованы два полных примера из датасета —
это осознанный выбор, источник и так открыт на Hugging Face.
