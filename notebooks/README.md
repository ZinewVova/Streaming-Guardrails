# Ноутбуки

- `01_singstreambench_eda.ipynb` проверяет происхождение, схему, 210 строк, четыре
  сочетания query/response labels, длины и точность onset/safe-prefix.
- `02_streaming_benchmark.ipynb` показывает конфигурацию Qwen3Guard, политики, шесть
  режимов буфера и загружает сохранённые результаты и CI. Каждый раздел сопровождается
  графиком: матрицы ошибок, FPR/FNR с Wilson CI, потокенная трасса одного примера,
  смещение сигнала относительно onset, ECDF и bootstrap CI leakage, стоимость режима и
  парное сравнение с эталонным режимом.

Расчёты находятся в `src/streamguard_bench`; notebook только вызывает функции и строит
визуализации. Подготовка окружения: `uv sync --extra analysis --extra dev` (добавьте
`--extra models`, если будете запускать guard-модель). Открывать ноутбуки удобно в VS
Code с расширениями Python и Jupyter: выберите ядро из `.venv` и нажмите Run All.

Файлы хранятся вместе с выводами, чтобы графики были видны без запуска. Перед коммитом
очищайте outputs `01_singstreambench_eda.ipynb`: там напечатаны полные тексты двух
примеров датасета.
