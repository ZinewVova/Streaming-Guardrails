# Ноутбуки

- `01_singstreambench_eda.ipynb` проверяет происхождение, схему, 210 строк, четыре
  сочетания query/response labels, длины и точность onset/safe-prefix.
- `02_streaming_benchmark.ipynb` показывает конфигурацию Qwen3Guard, политики, шесть
  режимов буфера и загружает сохранённые результаты и CI. Каждый раздел сопровождается
  графиком: матрицы ошибок запроса и ответа, FPR/FNR с Wilson CI, потокенная трасса
  каждого примера, смещение сигнала относительно onset, leakage с bootstrap CI по
  режимам и парное сравнение с эталонным режимом.
- `03_scm_benchmark.ipynb` проходит те же трассы моделью SCM-0.5B с правилом остановки
  Harm@k: качество блокировки ответа, потокенные вероятности на четырёх примерах,
  смещение сигнала, leakage по режимам буфера, чувствительность к порогу θ и числу
  флагов k, парное сравнение с Qwen3Guard-Stream и время проверки токена. Для сравнения
  нужен сохранённый прогон обеих моделей.

Расчёты находятся в `src/streamguard_bench`; notebook только вызывает функции и строит
визуализации. Подготовка окружения: `uv sync --extra analysis --extra dev` (добавьте
`--extra models`, если будете запускать guard-модель). Открывать ноутбуки удобно в VS
Code с расширениями Python и Jupyter: выберите ядро из `.venv` и нажмите Run All.

Файлы хранятся вместе с выводами, чтобы таблицы и графики были видны без запуска. В
`01_singstreambench_eda.ipynb` при этом опубликованы два полных примера из датасета —
это осознанный выбор, источник и так открыт на Hugging Face.
