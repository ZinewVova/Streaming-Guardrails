# Контракт нормализованных данных StreamSafe

## Назначение

Единицей данных является **трасса**: неизменённый запрос пользователя, полный ответ
ассистента и упорядоченные аннотации его префиксов. Локальные таблицы Parquet содержат
чувствительный текст и не добавляются в Git. Публичные отчёты содержат только агрегаты,
хэши и идентификаторы.

## `NormalizedTrace`

| Поле | Тип | Смысл |
|---|---|---|
| `trace_id` | строка | Первые 20 символов SHA-256 от неизменённых `prompt`, нулевого разделителя и `response`. |
| `source_split` | строка | Исходная часть `train` или `val`. |
| `prompt` | строка | Запрос без очистки и переформатирования. |
| `response` | строка | Полный ответ без очистки и переформатирования. |
| `binary_label` | `safe`, `unsafe` или пусто | Нормализованная бинарная метка. |
| `original_label` | строка | Исходная метка StreamSafe. |
| `harm_categories` | кортеж строк | Категории в порядке первого появления, без повторов. |
| `prefix_annotations` | кортеж | Упорядоченные размеченные префиксы. |
| `harm_onset` | объект или пусто | Интервал первого появления опасного содержания. |
| `language` | строка | Язык, на текущем выпуске `en`. |
| `source_rows` | кортеж чисел | Номера исходных строк, участвовавших в трассе. |
| `dataset_revision` | строка | Неизменяемый хэш ревизии StreamSafe. |
| `exclusion_reason` | строка или пусто | Причина исключения из бинарного поднабора. |

В Parquet вложенные поля записываются как JSON в столбцах с суффиксом `_json`.

## Префиксная аннотация

`end_character` и `end_byte` — исключающие правые границы префикса. Предложения
нумеруются с единицы. Несколько одинаковых префиксов с одинаковой разметкой объединяются,
а все их исходные строки сохраняются. Конфликт меток на одной позиции исключает трассу
из автоматического выбора.

## Граница появления вреда

StreamSafe размечает префиксы на границах предложений, поэтому автоматически известен
не точный символ, а интервал:

- `lower_character` — конец предыдущего размеченного префикса;
- `upper_character` — конец первого префикса с меткой `unsafe`;
- нижняя граница включается, верхняя не включается;
- байтовые позиции вычисляются в UTF-8;
- токенные позиции относятся только к ответу, без служебных токенов шаблона;
- токен, пересекающий символьную границу, считается первым токеном интервала.

Поля `exact_*` остаются пустыми до ручной проверки. Токенизатор закреплён в
`configs/data_subset_v1.yaml`; при смене токенизатора токенные координаты пересчитываются
из исходных символьных позиций.

## Метки и исключения

- `safe` и `unsafe` включаются в бинарный пул;
- `uncertain`, пустые и неизвестные метки сохраняются, но исключаются из поднабора;
- несколько категорий разрешены;
- отсутствие категории у `unsafe` создаёт предупреждение;
- несопоставленные и неоднозначные префиксы записываются в полный локальный журнал;
- ни одна исходная строка не исправляется догадкой и не удаляется молча.

## Артефакты и воспроизводимость

Поднабор строится с начальным состоянием генератора случайных чисел 42. Перед выбором
кандидаты сортируются по `trace_id`. Манифесты содержат ревизии, параметры, список
контрольных сумм и SHA-256 итогового Parquet. Повторный запуск на тех же ревизиях должен
дать тот же набор идентификаторов.

## Публичный выпуск

Полный производный набор опубликован в
[Vovarus12go/streamsafe-500-boundaries](https://huggingface.co/datasets/Vovarus12go/streamsafe-500-boundaries)
на ревизии `34a4b07f442b9254858388a7f9662f405176bbcb`. Он содержит исходные поля `prompt`
и `response`, но не дублирует тексты префиксов: каждый префикс восстанавливается как
`response[:prefix_end_characters[i]]`. Карточка набора содержит атрибуцию StreamSafe,
предупреждение о чувствительном содержании и описание интервальной семантики границ.
