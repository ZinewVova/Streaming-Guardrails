# Установка и запуск

## Окружение

Нужны Python 3.11, [uv](https://docs.astral.sh/uv/) и `make`. Команды запускаются из
корня репозитория.

```bash
make install
```

Этого достаточно, чтобы читать ноутбуки и запускать тесты. Для запуска guard-моделей
нужны ещё torch и transformers, а также подготовленный датасет:

```bash
make install-models
```

```bash
make data
```

Проверить окружение можно так же, как это делает CI:

```bash
make check
```

## Запуск прогонов

Модель выбирается именем конфига из `configs/`; без `MODEL` берётся
`qwen3guard_baseline`. `make models` показывает доступные конфиги, `make help` — все
команды.

Проверка кода на двух трассах:

```bash
make smoke MODEL=scm_0_5b
```

Полный прогон на 210 трассах:

```bash
make full MODEL=scm_0_5b
```

CSV-отчёты по сохранённому прогону:

```bash
make reports MODEL=scm_0_5b PROFILE=full
```

Готовый прогон читается с диска и не пересчитывается, прерванный продолжается с
последней сохранённой трассы. Результаты лежат в `data/interim/` вне Git, поэтому после
клонирования репозитория прогоны нужно получить заново.

Команды `make` — короткие обёртки над `uv run`; сами вызовы видны в `Makefile`, их можно
выполнять и напрямую.

### Правило остановки

У каждой модели оно своё и задаётся в конфиге полями `experiment.trigger_count` и
`experiment.trigger_mode`:

- Qwen3Guard-Stream: два блокирующих токена подряд (`consecutive`, 2);
- SCM: четыре токена с вероятностью вреда не ниже `model.threshold` в любом месте ответа
  (`cumulative`, 4).

Решения по токенам от правила не зависят. Смена правила в конфиге не запускает модель
заново: следующий прогон переиграет сохранённые трассы.

### Новая модель

1. Адаптер в `src/streamguard_bench/guards/` с методами `tokenize_response`, `start`,
   `score_token` и `close`.
2. Конфиг в `configs/` с ревизией модели и правилом остановки.
3. Прогон: `make full MODEL=<имя конфига>`.

Сводный ноутбук `06_model_comparison.ipynb` подхватит модель сам, как только у неё
появится сохранённый полный прогон.

## Что где лежит

| Путь | Содержимое |
|---|---|
| `notebooks/` | разбор датасета, прогонов и сравнение моделей |
| `src/streamguard_bench/` | загрузка данных, адаптеры guard-моделей, движок replay, метрики и графики |
| `scripts/` | подготовка данных, запуск модели, сборка отчётов |
| `configs/` | по файлу на модель: ревизии датасета и модели, режимы, политики, правило остановки |
| `tests/` | тесты на контракт данных, адаптеры, движок, метрики и графики |
| `reports/tables/` | CSV-отчёты полного прогона Qwen3Guard-Stream; отчёты других моделей в подпапках |
| `data/` | кеш, подготовленный Parquet и результаты прогонов, всё вне Git |
| `docs/` | эта инструкция и [описание полей подготовленного датасета](data_contract.md) |
