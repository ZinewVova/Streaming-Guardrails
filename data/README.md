# Правила хранения данных

В Git добавляются только полностью искусственные тестовые записи и пустые шаблоны.
Настоящие файлы StreamSafe загружаются в `data/raw/streamsafe/` и исключены из Git.
Промежуточные таблицы сохраняются в `data/interim/`, нормализованный пул и поднабор —
в `data/processed/`. Эти каталоги содержат чувствительный текст и не публикуются.

Исходный набор содержит чувствительные примеры, предназначенные для исследования безопасности. Полные запросы и ответы нельзя копировать в задачи, запросы на слияние, журналы выполнения, ноутбуки и снимки экрана.

Содержимое каталогов:

- `fixtures/` — небольшие искусственные данные для автономных тестов;
- `raw/` — неизменённые файлы источника и манифест загрузки;
- `interim/` — полный журнал исключений, приватная таблица для ручного аудита и рабочие файлы;
- `processed/` — локальный нормализованный пул, поднабор 500 и манифесты контрольных сумм.

Публично сохраняются только агрегаты из `reports/tables/`: распределения, хэши,
идентификаторы трасс и ручные аннотации без запросов и ответов.
